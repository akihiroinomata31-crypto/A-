# Arena stone floor

Source: https://ambientcg.com/view?id=PavingStones036
License: CC0 (https://docs.ambientcg.com/license/)
File: PavingStones036_Color.jpg, original 2K JPG color map.

The game draws the original stage's floor triangles with planar repeating UVs
(600 world units per tile). Stage_4545.mv1, its circular boundary, walls and
collision remain unchanged. Texture loading failure retains the original floor.
Only the color map is used; no PBR normal/displacement support is assumed.
