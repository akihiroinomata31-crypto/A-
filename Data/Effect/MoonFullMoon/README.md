# Player 2 full moon slash

Player 2 normal attacks use SwordGlowMoonFullMoonFree.efkefc. Player 1 uses LunarEclipse.
Only the ordinary slash is imported; the Spiral effect is not used.
The original effect and its four image dependencies are preserved unchanged.
Source: user-provided SwordGlowMoonFullMoonFree package by Orimart.
See the bundled original product information and terms.

Runtime scale: 20; playback speed: 1.0. Parameters are in Project10/player.h.
Per-player playback settings survive match resets.
--player-smoke checks all four runtime textures, combo replay, independent player handles,
cleanup, and cancellation into skills. Add --moon-preview to save preview frames to work/.
